Read the code The pipeline

Four questions, one pipeline

  1. Can it learn?

    Decision tree, RBF SVM and MLP trained on D1.

  2. Does it hold?

    Accuracy, F1, confusion matrices and ROC on held-out D1.

  3. Does it survive the shift?

    The same D1 models scored on D2’s test split.

  4. Can it recover?

    The MLP fine-tunes on D2 from its D1 weights; the tree and SVM retrain on both.

The target is any diagnosis of one condition, chosen from the 15 most prevalent.

What the features may not see

  • Healthcare expensesA financial outcome, dropped from the features.Excluded
  • Comorbidity countCounts every condition except the target, so positives are not guaranteed a 1.Target removed
  • Medication, procedure and observation aggregatesCover the whole record, including treatment after diagnosis. Cutting each history at the diagnosis date is the fix.Open

Run

Put the seven Synthea-style CSVs in Dataset/ beside the script; they are not committed. Without them it stops at patients.csv.

python3 -m venv .venv && . .venv/bin/activate
pip install streamlit pandas numpy scikit-learn plotly
streamlit run "Temporal EHR Intelligence Platform.py"
